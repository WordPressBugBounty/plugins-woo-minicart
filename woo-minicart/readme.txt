The simple plugin to add a minicart on your WooCommerce store. Choose from multiple cart icons, adjust position, and optionally use the shortcode.

== Description ==
Minicart for WooCommerce lets you quickly add a minicart to your WooCommerce store.  

**Features (Free):**
- Enable or disable floating minicart.
- Choose position (Top Left, Top Right, Bottom Left, Bottom Right).
- 5 built-in cart icons to select from.
- Set vertical offset for top positions.
- Shortcode `[woo-minicart]` available in free version.

**Pro Version:**
- More built-in cart icons.
- Upload your own custom cart icon.
- Advanced styling options (colors, buttons, header).
- Dedicated support and lifetime updates.  
👉 [Go Pro](https://eshaldevs.com/product/minicart-for-woocommerce-pro/)

== Installation ==
1. Ensure WooCommerce is installed and activated.
2. Upload the plugin or install via **Plugins → Add New** and search for **"woo-minicart"**.
3. Activate the plugin.
4. Go to **Woo Minicart → Settings** to choose your icon, position, and options.
